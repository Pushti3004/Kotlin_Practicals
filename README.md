# Practical-1: Kotlin Programs

## Aim
To develop Kotlin programs demonstrating fundamental programming concepts, including variables, type conversion, input/output, control flow, functions, recursion, arrays, collections, classes, constructors, operator overloading, and matrix operations.

## Tools Required
- IntelliJ IDEA
- Kotlin
- JDK (Java Development Kit)

## Practical Objectives

### 1.1 Store & Display Values in Different Variables
Create and display variables using different Kotlin data types:
- Integer (`Int`)
- Double (`Double`)
- Float (`Float`)
- Long (`Long`)
- Short (`Short`)
- Byte (`Byte`)
- Character (`Char`)
- Boolean (`Boolean`)
- String (`String`)

### 1.2 Type Conversion
Perform type conversions between different data types, including:
- Integer to Double
- String to Integer
- String to Double

### 1.3 Scan Student's Information and Display All the Data
Accept and display student information such as:
- Name
- Enrollment Number
- Branch
- Semester
- College details

### 1.4 Check Odd or Even Numbers
Accept an integer from the user and determine whether it is odd or even using Kotlin control flow directly within the `println()` statement.

### 1.5 Display Month Name
Accept a month number from the user and use a Kotlin `when` expression to display the corresponding month name.

### 1.6 User-Defined Function
Create a user-defined function to perform basic arithmetic operations on two numbers:
- Addition
- Subtraction
- Multiplication
- Division

### 1.7 Factorial Calculation with Recursion
Implement a recursive function to calculate the factorial of a given number.

**Formula:**

`n! = n × (n-1) × (n-2) × ... × 1`

### 1.8 Working with Arrays
Demonstrate different array operations, including:
- `Arrays.deepToString()`
- `contentDeepToString()`
- `IntArray.joinToString()`
- Printing and traversing arrays
- Using `range`
- Using `downTo`
- Using `until`
- Sorting an integer array without built-in functions
- Sorting an integer array using built-in functions

### 1.9 Find Maximum Number from ArrayList
Create an `ArrayList` of integers and find the maximum value stored in the list.

### 1.10 Class and Constructor Creation
Create a `Car` class with properties such as:
- Type
- Model
- Price
- Owner
- Miles Driven

Implement functions to:
- Get car information
- Display original car price
- Calculate/display current car price
- Display complete car information

### 1.11 Operator Overloading and Matrix Operations
Demonstrate operator overloading using a `Matrix` class.

Implement:
- Matrix addition
- Matrix subtraction
- Matrix multiplication
- Customized `toString()` function for displaying matrix objects

Kotlin operator overloading allows operators such as `+`, `-`, and `*` to be given specific behavior for user-defined classes.

## Expected Learning Outcomes
After completing this practical, the student will be able to:

1. Understand Kotlin's basic data types and variables.
2. Perform type conversion between different data types.
3. Take input from users and display formatted output.
4. Apply conditional statements and `when` expressions.
5. Create and use user-defined functions.
6. Understand recursion through factorial calculation.
7. Work with arrays, loops, and collections.
8. Implement classes and constructors in Kotlin.
9. Understand operator overloading.
10. Perform matrix operations using object-oriented programming concepts.

## Conclusion
This practical introduces the fundamental concepts of Kotlin programming and object-oriented programming. It provides hands-on experience with variables, data types, input/output, control flow, functions, recursion, arrays, collections, classes, constructors, operator overloading, and matrix operations.
